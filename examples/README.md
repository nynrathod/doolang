# Doo Examples

Learn Doo patterns through clean, standalone code.

## Static Examples (No Database)

| Example | What You'll Learn |
|---------|-------------------|
| [hello_world](./hello_world/) | Basic syntax, variables, loops |
| [calculator](./calculator/) | Error handling (`!`, `?`), multi-file |
| [clean_code](./clean_code/) | Struct methods, services, validation |
| [tasks](./tasks/) | Enums, filtering, store pattern |
| [error_handling](./error_handling/) | `!`, `?`, `??` operators, auto & manual error handling |
| [config_json](./config_json/) | JSON parsing, config handling |

## API Example (With Database)

| Example | What You'll Learn |
|---------|-------------------|
| [tasks_api](./tasks_api/) | Converting static code → API endpoints |

## Production Templates

For shipping APIs, use templates:

```bash
doo init starter  # Simple hello API
doo init todo     # CRUD + Auth
doo init blog     # Relations + Custom handlers
```
