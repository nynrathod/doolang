# Language Feature Tests

Raw examples demonstrating Doo language features.

| Folder | What It Tests |
|--------|---------------|
| `array/` | Array operations, methods |
| `condition/` | If/else, boolean logic |
| `database/` | DB queries, connections |
| `enum/` | Enum declarations, matching |
| `error_handling/` | `!`, `?`, `??`, error propagation |
| `file/` | File I/O operations |
| `find_in/` | Search operations |
| `function/` | Function definitions, closures |
| `http/` | HTTP client/server primitives |
| `import/` | Module imports |
| `inbuilt/` | Built-in functions |
| `json/` | JSON parsing, stringify |
| `maps/` | Dictionary operations |
| `match/` | Pattern matching |
| `operators/` | Arithmetic, logical operators |
| `print/` | Output formatting |
| `return_type/` | Type inference, returns |
| `struct/` | Struct methods, field access |
| `type_handle/` | Type conversions |
| `utf8/` | Unicode handling |

## Run

```bash
doo run folder_name/test_file.doo
```
